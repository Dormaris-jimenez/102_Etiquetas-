102 Etiquetas HTML

Listado de 102 etiquetas de HTML

N°EtiquetaDescripciónEjemplo
1<html>Elemento raíz de un documento HTML; contiene <head> y <body>.
<!doctype html>
    <html lang="es">...</html>
2<head>Contiene metadatos, enlaces a estilos, título y scripts que no se muestran directamente.
<head><title>Mi página</title></head>
3<title>Define el título de la página mostrado en la pestaña del navegador.
<title>Ejemplo</title>
4<base>Establece la URL base para los enlaces relativos del documento.
<base href="https://example.com/">
5<link>Enlaza recursos externos como hojas de estilo (CSS) o favicons.
<link rel="stylesheet" href="styles.css">
6<meta>Metadatos: codificación, viewport, descripción, etc.
<meta name="viewport" content="width=device-width,initial-scale=1">
7<style>Incluye CSS en línea dentro del documento.
<style>body{font-family:Arial}</style>
8<script>Contiene o enlaza código JavaScript.
<script>console.log('hola')</script>
9<noscript>Contenido mostrado cuando JavaScript está deshabilitado.
<noscript>Activa JavaScript para ver esta página.</noscript>
10<body>Contiene el contenido visible de la página (texto, imágenes, etc.).
<body><p>Hola</p></body>
11<section>Sección genérica del documento, para agrupar contenido temático.
<section><h2>Servicios</h2></section>
12<nav>Contenedor para enlaces de navegación principal.
<nav><a href="#">Inicio</a></nav>
13<article>Contenido independiente y auto-contenido, como una entrada de blog.
<article><h2>Noticia</h2></article>
14<aside>Contenido relacionado lateralmente (ej. barras laterales, widgets).
<aside>Enlaces relacionados</aside>
15<header>Encabezado de una sección o página (logo, título, navegación secundaria).
<header><h1>Mi sitio</h1></header>
16<footer>Pie de página con copyright, enlaces legales, etc.
<footer>&copy; 2025 Mi empresa</footer>
17<address>Información de contacto del autor o del documento.
<address>Calle Falsa 123</address>
18<h1>Encabezado de nivel 1; el más importante en jerarquía.
<h1>Título principal</h1>
19<h2>Encabezado de nivel 2.
<h2>Subtítulo</h2>
20<h3>Encabezado de nivel 3.
<h3>Sección</h3>
21<h4>Encabezado de nivel 4.
<h4>Subsección</h4>
22<h5>Encabezado de nivel 5.
<h5>Tema menor</h5>
23<h6>Encabezado de nivel 6; menos usado.
<h6>Nota</h6>
24<p>Parrafo de texto.
<p>Este es un párrafo.</p>
25<hr>Regla horizontal; separador temático entre bloques.
<hr>
26<br>Inserta un salto de línea (break).
27<pre>Texto preformateado; respeta espacios y saltos de línea.
<pre> Texto con
    espacios</pre>
28<blockquote>Cita larga o bloque citado de otra fuente.
<blockquote>Cita extensa.</blockquote>
29<ol>Lista ordenada (numerada).
<ol><li>Primero</li></ol>
30<ul>Lista no ordenada (viñetas).
<ul><li>Elemento</li></ul>
31<li>Elemento de lista (usado dentro de <ol> o <ul>).
<li>Elemento de lista</li>
32<dl>Lista de definiciones (definition list).
<dl><dt>HTML</dt><dd>Lenguaje de marcado</dd></dl>
33<dt>Término en una lista de definiciones.
<dt>Término</dt>
34<dd>Descripción del término en una lista de definiciones.
<dd>Definición</dd>
35<figure>Contenedor para contenido ilustrativo (imagen, gráfico) con <figcaption>.
<figure><img src="img.jpg" alt=""></figure>
36<figcaption>Pie o leyenda de una figura.
<figcaption>Descripción de la imagen</figcaption>
37<main>Contenido principal único de la página (solo uno por documento).
<main>Contenido principal</main>
38<div>Contenedor genérico de bloque; usado para agrupar y estilizar.
<div class="card">Contenido</div>
39<a>Enlace (anchor). Navega a otra URL o a un ancla interna.
<a href="https://example.com">Ir</a>
40<em>Texto enfatizado (semántica: énfasis).
<em>Importante</em>
41<strong>Texto con fuerte importancia; normalmente se ve en negrita.
<strong>Atención</strong>
42<small>Texto de menor importancia o nota al pie.
<small>Nota</small>
43<s>Texto tachado que indica contenido obsoleto o incorrecto.
<s>Precio antiguo</s>
44<cite>Título de una obra o referencia (cita bibliográfica).
<cite>Nombre del libro</cite>
45<q>Cita corta en línea; se renderiza con comillas en muchos navegadores.
<q>Breve cita</q>
48<data>Asocia un valor legible por máquina con un contenido legible por humanos.
<data value="42">cuarenta y dos</data>
49<time>Representa una fecha/hora legible por máquina opcionalmente con atributo datetime.
<time datetime="2025-09-15">15 sept 2025</time>
50<code>Fragmento de código en línea.
<code>console.log()</code>
51<var>Nombre de una variable o una representación de una variable.
<var>x</var> = 5;
52<samp>Muestra la salida de un programa o ejemplo de ejecución.
<samp>OK</samp>
53<kbd>Entrada de teclado (teclas a pulsar).
<kbd>Ctrl+C</kbd>
54<sub>Texto en subíndice.
H<sub>2</sub>O
55<sup>Texto en superíndice.
x<sup>2</sup>
56<i>Texto en cursiva; semántica en itálica (por ejemplo, términos técnicos).
<i>palabra en cursiva</i>
57<b>Texto en negrita sin semántica fuerte (estético).
<b>texto</b>
58<u>Subraya texto (puede indicar énfasis o términos en idiomas distintos).
<u>subrayado</u>
59<mark>Texto marcado/seleccionado (resaltado).
<mark>resaltado</mark>
60<ruby>Contenedor para anotaciones ruby (p. ej. en idiomas asiáticos).
<ruby>漢<rt>kan</rt></ruby>
61<rt>Texto de la anotación ruby (pronunciación/símbolo pequeño).
<rt>furigana</rt>
62<rp>Provee paréntesis para navegadores que no soportan ruby.
<rp>(</rp><rt>...</rt><rp>)</rp>
63<bdi>Aísla la dirección del texto para soportar mezclas LTR/RTL (bidireccional).
<bdi>texto</bdi>
64<bdo>Anula la dirección del texto (dir="rtl" o "ltr").
<bdo dir="rtl">texto</bdo>
65<span>Contenedor en línea genérico; útil para aplicar estilos o identificar texto.
<span class="highlight">texto</span>
66<img>Inserta una imagen (atributos src y alt recomendados).
<img src="foto.jpg" alt="Descripción">
67<iframe>Marco inline que carga otro documento HTML (p. ej. un video embebido).
<iframe src="https://example.com" title="Demo"></iframe>
68<embed>Inserta contenido embebido de tipo plugin (menos usado hoy).
<embed src="file.pdf" type="application/pdf">
69<object>Contenedor para recursos multimedia o plug-ins; alternativa a <embed>.
<object data="file.svg" type="image/svg+xml"></object>
74<track>Pistas de subtítulos o captions para <video> (atributo kind).
<track kind="subtitles" src="sub.vtt" srclang="es" label="Esp">
75<canvas>Lona de dibujo para gráficos dinámicos vía JavaScript (API 2D/3D).
<canvas id="miCanvas" width="200" height="100"></canvas>
76<map>Mapa de imagen que define áreas clicables vinculadas.
<map name="mapa">...</map>
77<area>Área dentro de un <map> con coordenadas y enlace.
<area shape="rect" coords="0,0,100,100" href="#">
78<svg>Gráficos vectoriales escalables embebidos en HTML.
<svg width="100" height="50"><rect width="100" height="50"/></svg>
79<math>Contenedor para MathML (expresiones matemáticas).
<math><mi>x</mi></math>
80<table>Tabla de datos estructurada en filas y columnas.
<table><tr><td>A</td></tr></table>
81<caption>Título o leyenda de la tabla (<table>).
<table><caption>Ventas</caption></table>
82<colgroup>Agrupa columnas en una tabla y permite aplicar estilos/atributos.
<colgroup><col span="2"/></colgroup>
83<col>Define atributos para una columna de tabla específica.
<col style="width:50%">
84<tbody>Cuerpo principal de filas (<tr>) en una tabla.
<tbody><tr><td>Dato</td></tr></tbody>
85<thead>Encabezado de la tabla (filas con <th>).
<thead><tr><th>Col</th></tr></thead>
86<tfoot>Pie de la tabla (resumen o totales).
<tfoot><tr><td>Total</td></tr></tfoot>
87<tr>Fila de la tabla; contiene celdas <td> o <th>.
<tr><td>Celda</td></tr>
88<td>Celda de datos en una tabla.
<td>Dato</td>
89<th>Celda de encabezado en una tabla (normalmente centrada y en negrita).
<th>Encabezado</th>
90<form>Formulario para entrada de datos, envío al servidor o procesamiento.
<form action="/enviar" method="post">...</form>
91<fieldset>Agrupa controles relacionados dentro de un formulario.
<fieldset><legend>Datos</legend></fieldset>
92<legend>Título para un <fieldset>.
<legend>Información personal</legend>
93<label>Etiqueta asociada a un control de formulario (<input>, <select>).
<label for="email">Email</label><input id="email"/>
94<input>Control de entrada (texto, checkbox, radio, file, etc.).
<input type="text" name="nombre">
95<button>Botón interactivo (submit, reset o botón genérico).
<button type="submit">Enviar</button>
96<select>Lista desplegable (combobox) que contiene <option>.
<select><option>A</option></select>
97<datalist>Provee sugerencias autocompletadas para un <input> asociado.
<datalist id="list"><option value="Rojo"></datalist>
98<optgroup>Grupo de <option> dentro de un <select> para organizar opciones.
<optgroup label="Frutas"><option>Manzana</option></optgroup>
99<option>Opción individual dentro de <select> o <datalist>.
<option value="1">Uno</option>
100<textarea>Área de texto multilinea para entrada extendida del usuario.
<textarea rows="4" cols="30"></textarea>
101<output>Elemento para mostrar el resultado de un cálculo (formulario/JS).
<output name="suma">0</output>
102<progress>Barra que indica progreso de una tarea (valor y max).
<progress value="30" max="100">30%</progress>
